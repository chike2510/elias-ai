## Extended description

Elias AI is a user-owned intelligence workspace for coding, research, and delivery. Users can connect selected Vercel teams and projects so Elias can inspect project context, review deployment status, and help produce evidence-backed work without exposing access to unrelated resources.

## Overview

```markdown
## Elias AI

Elias is a user-owned AI workspace for coding, research, and delivery. Connect selected Vercel projects so Elias can inspect context, review deployments, and help turn objectives into verifiable work.

Elias requests only the Vercel scopes needed for the connected workspace. Access is initiated by the user from the Elias **+ add** menu and can be revoked from the provider account at any time.
```
